Music playback

Played songs are kept for faster skips and replays. Starred, playlist and frequently played songs are kept ready as FLAC when Monochrome is available, using up to half the cache. 0 turns caching off.

Save favourites to your library

Albums you mark as a favourite (the heart on an album in the Music channel, or a star in a Subsonic app) are saved here as tagged FLAC files, one folder per artist and album, so they play offline and in any music app. Use a folder of a Jellyfin music library that Jellyfin can write to. Existing files are never replaced, and albums are saved slowly (one song every 20 seconds) to stay within the catalog's limits. Leave empty to save nothing.

    Advanced music tools & connections
    Use your own yt-dlp instead of the downloaded one. Leave empty to let StreamFin manage it.
    Use your own deno instead of the downloaded one. Leave empty to let StreamFin manage it.
    YouTube refuses many data centre addresses ("Sign in to confirm you're not a bot"). Every YouTube search and download then goes through this proxy instead, for example a VPN container next to Jellyfin: http or socks5, with a host and port. Nothing else StreamFin fetches uses it.
    Radio mixes an artist with similar ones, as ListenBrainz knows them. For artists ListenBrainz has no data on, a free key from last.fm/api is used as well.

    User access

    Nobody can see StreamFin channels or use its Subsonic API until they are allowed here. An app password alone does not grant access.

    Subsonic apps

    For Symfonium, Feishin, Tempo, play:Sub and other Subsonic apps. In the app, use the server address , the Jellyfin username, and that person's app password below (not their Jellyfin password).
    Some apps, Amperfy among them, ask for MP3 by default. With this on they get the original FLAC instead, which sounds better and seeks faster. A data saving limit in the app still gets a smaller converted file.

    People

    One card per Jellyfin user. Allow access, then create an app password if they use a Subsonic app. A new password replaces the old one when you save.
